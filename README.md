🎯 Java Quiz Application

A desktop-based quiz application developed using Java Swing and MySQL. The application allows users to register, log in, select quiz categories and difficulty levels, answer multiple-choice questions, and view their results.

📌 Project Overview

The Java Quiz Application provides an interactive platform for practicing technical questions across multiple programming and computer science subjects. It includes a countdown timer, randomized questions, automatic score calculation, and answer review.

✨ Features

User Registration & Login — Create an account and log in.

Multiple Quiz Categories — Java, Python, SQL, and Data Structures.

Difficulty Levels — Easy, Medium, and Hard.

Random Questions — Questions are selected randomly from the database.

Timed Quiz — 90 seconds to complete each quiz.

Five Questions per Quiz — Each quiz is designed to contain five questions.

Automatic Scoring — Calculates the score based on submitted answers.

Answer Review — Review selected answers and correct answers after submission.

Interactive GUI — User-friendly interface built with Java Swing.

Database Integration — Stores questions and user information in MySQL.
